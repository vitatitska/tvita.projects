# tvita.projects
🛒 Simple Shop & Order Management System

Це інтерактивна консольна система для автоматизації покупок, розроблена на мові C++. Програма дозволяє керувати віртуальним складом, формувати кошик покупок та генерувати фінансові звіти.

🌟 Опис функціонала програми
Цей проєкт — це цифрова екосистема для керування замовленнями, побудована на взаємодії двох ключових сутностей: Товару та Замовлення. Програма перетворює консоль на зручне робоче місце адміністратора або покупця.

🏗️ Логічна архітектура
В основі лежать три компоненти, що працюють як єдиний механізм:

📦 Об'єктна модель товару (Product): Кожна одиниця має своє ім'я, ціну та кількість. Програма вміє гарно форматувати ці дані у вигляді таблиці, щоб користувачу було приємно на них дивитися.

🛒 Розумний кошик (Order): Це "серце" системи. Він не просто зберігає товари, а й:

Групує дублікати: Якщо ви додаєте той самий товар двічі, програма не створює новий запис, а просто оновлює кількість.

Керує станом: Замовлення може бути в статусі очікування, завершеним або скасованим.

Рахує гроші: Автоматично обчислює загальну вартість, враховуючи кожну одиницю товару.

💾 Робота з даними: Програма автономна. Вона сама створює базу товарів (stock.txt) при першому запуску та вміє генерувати детальні фінансові звіти у текстові файли.

🛠️ Можливості, які доступні користувачу

Перегляд вітрини: Виведення повного списку доступних товарів із актуальними цінами 🏷️.

Гнучке редагування: Можна додавати товари до кошика, видаляти їх, якщо передумали, або змінювати кількість "на льоту" 🔄.

Контроль замовлення: Встановлення дати оформлення та зміна статусу (наприклад, з "В обробці" на "Виконано") 🚥.

Генерація чеків: Створення професійного звіту, який містить дату, статус, перелік покупок та фінальну суму до сплати 📑
